# Checklist pubblicazione menù — RenMenu

> Da usare dal Team RenMenu prima di pubblicare, inviare o stampare il QR di un cliente. Spunta solo ciò che è stato controllato sul materiale più recente ricevuto dal locale.

## 1. Materiale ricevuto

- [ ] Nome ufficiale del locale confermato
- [ ] Foto o PDF del menù ricevuto
- [ ] Versione/data del materiale annotata
- [ ] Recapito del referente confermato
- [ ] Logo e fotografie autorizzate, se utilizzati

## 2. Contenuti

- [ ] Piatti, prezzi e sezioni confrontati con il materiale del locale
- [ ] Allergeni confermati dal locale, senza supposizioni
- [ ] Piatti non disponibili, stagionali o “del giorno” verificati
- [ ] Coperto, servizio e note speciali verificati
- [ ] Indirizzo, orari, telefono, Instagram e Maps controllati

## 3. Lingue

- [ ] Lingua italiana verificata
- [ ] Lingua inglese verificata se inclusa
- [ ] Lingue aggiuntive confermate o indicate come da completare
- [ ] Nessuna traduzione inventata per allergeni, ingredienti o prezzi

## 4. Controllo tecnico

- [ ] JSON validato con `python3 scripts/validate-menus.py`
- [ ] Link del menù aperto dal browser
- [ ] Ricerca testata
- [ ] Cambio lingua testato
- [ ] Allergeni visualizzati correttamente
- [ ] Link telefono, Instagram e Maps testati se presenti
- [ ] QR scansionato e aperto su almeno un telefono
- [ ] Nessun errore, testo troncato o scorrimento orizzontale rilevato

## 5. Approvazione e consegna

- [ ] Anteprima inviata al referente
- [ ] Modifiche richieste registrate
- [ ] Approvazione scritta ricevuta via WhatsApp o email
- [ ] QR definitivo inviato o stampato
- [ ] URL definitivo annotato
- [ ] Data di pubblicazione registrata
- [ ] Materiale originale archiviato
