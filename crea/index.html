Compila, guarda l'anteprima, scarica il file .json e caricalo nella cartella menus/ del sito. Il QR punta sempre allo stesso link: puoi aggiornare il menù quante volte vuoi senza ristampare.

Il locale

Sezioni e piatti

Come si pubblica

  1. Scarica il file .json qui a lato.
  2. Su GitHub apri la cartella menus/ del sito e carica il file (Add file → Upload). Il nome deve essere identificativo.json.
  3. Dopo un minuto il menù è online al link indicato e il QR funziona. Per aggiornare, ricarica lo stesso file.
